Website Accessibility Evaluator

A separate tool that checks a page on its own, without the tester. You get a score from 0 to 100, what is missing and how to fix it. Run it in code review, before a release, or after every version to watch the score move.

  • Color and designContrast of every text element, with a compliant color suggested.
  • KeyboardFocus visibility, traps, skip link and focus order.
  • StructurePage title, language, viewport, headings and landmarks.
  • Content qualityAlt text, link text, form labels and autocomplete.
