Inspect harness

Acts like the Angular app: the page under test sits in an iframe, the sim scripts are injected into it, and the same postMessage protocol is used. Serve the repo root over http (python -m http.server 5500) and open http://localhost:5500/docs/test-harness.html. Opening it with file:// does not work, Chrome treats every file as its own origin.
